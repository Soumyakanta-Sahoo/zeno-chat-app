# Zeno V3 Beta

A real-time chat application with connection-based messaging.

## Features
- Real-time messaging (Socket.io)
- Connection request system
- Authentication system
- Unread messages & typing indicators

## Tech Stack
- Frontend: Next.js
- Backend: Node.js + Express
- Database: MongoDB
- Real-time: Socket.io

## Setup

### Backend
npm install
npm run dev

### Frontend
npm install
npm run dev
